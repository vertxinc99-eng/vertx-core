# VERTX CORE v1.1 AI

解体足場向けの資材注文・重量計算・トラック判定・図面管理・AI図面解析プロトタイプです。

## v1.1 AI の追加機能
- PDF / JPG / PNG の図面をAI解析
- 枠組足場 / 単管足場の判定補助
- 図面の寸法・注記を抽出
- 資材候補・数量・根拠・確信度を表示
- 既存の資材マスタと自動照合
- マッチした候補をワンタップで注文へ反映
- 重量と「乗る車」を自動再計算
- AIが使えない場合も従来の寸法アシストを残しています

## Vercel でAIを有効にする
1. GitHubにこのZIPの中身をアップロードします。`api/analyze.js` も必要です。
2. Vercelで対象プロジェクト `vertx-core` を開きます。
3. Settings → Environment Variables を開きます。
4. `OPENAI_API_KEY` を追加し、OpenAI APIキーを値に設定します。
5. 必要なら `OPENAI_MODEL` を追加します。未設定時は `gpt-5` を使います。
6. 保存後に Redeploy します。

重要: APIキーを `app.js` や `index.html` に直接書かないでください。APIキーはVercel側だけに保存します。

## AI解析について
- AI結果は発注確定ではなく「候補」です。
- 足場図面の納まり、開口、階段、朝顔、壁つなぎ、養生、メーカー仕様は必ず人が確認してください。
- 現在は1ファイル4MB以下を推奨しています。大きいPDFは必要なページを画像保存して解析してください。
- 解析内容はOpenAI APIへ送信されます。
