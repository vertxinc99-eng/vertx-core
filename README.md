# VERTX CORE v2.1 AI

解体足場向け資材注文・現場管理アプリ。

## v2.1
- 枠組 / 単管中心の資材マスタ
- カテゴリ検索・お気に入り
- 重量 kg/t 自動計算・最小推奨車両
- 現場管理・注文履歴・前回コピー
- PDF/印刷・LINE共有
- 図面アップロード
- AI図面解析 (`/api/analyze`)
- AI新旧図面比較 (`/api/compare`)
- 現場資材の手動管理
- 不足材クイック追加
- よく使う資材セット
- 配車予定・注文ステータス

AI機能には Vercel Environment Variables の `OPENAI_API_KEY` が必要です。
AI解析は補助機能です。数量・納まり・積載可否は最終的に人が確認してください。


## v2.1 自動在庫
- 注文ステータスが「納品済」になった時点で、その注文の資材数量を現場在庫へ自動加算します。
- 同じ注文は二重加算しません。
- 現場在庫は手動補正も可能です。
