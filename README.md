# VERTX CORE β0.5.1

β0.5からの追加:
- 足場材マスタを大幅追加（枠、アンチ/布板、筋交/手摺、ジャッキ/ベース、単管、クランプ/金物、ブラケット、階段/昇降、養生、朝顔ほか）
- 合計重量を kg / t の両方で表示
- 注文確認で資材ごとの重量小計を表示
- トラック表示を「積める最小クラス1台」だけに変更（軽トラ/2t/3t/4t/6t/8t/10t）
- 検索用の別名（4mパイプ、4板、鬼クラ等）を追加

※単重は標準的な参考値を含みます。実際の使用メーカー・型式に合わせてマスタ値を調整してください。トラックは車種・架装で最大積載量が異なるため、最終判断は車検証の最大積載量を確認してください。
