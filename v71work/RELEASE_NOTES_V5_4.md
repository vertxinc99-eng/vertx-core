# VERTX CORE v5.4 FIELD OS

## 追加・変更
- 資材注文画面の各資材カード右上「•••」から会社別の表示名・単重・カテゴリーを直接編集
- 使わない資材を会社単位で注文画面から非表示
- 変更内容は既存 tenant_store 経由で会社単位クラウド同期
- 社員/職長が保存した注文は「承認待ち」、社長/管理者は注文履歴から承認可能
- 注文確認の CORE CHECK を見やすく刷新
- UIを FIELD OS デザインへ全面刷新
- 下部ナビを HOME / SITES / ORDER / AI / MORE に刷新
- MORE に会社設定・権限・資材マスタ・配車・分析・プラン・マニュアルを集約
- マニュアルを v5.4 操作に更新

## DB
v5.3 の role invite migration を実行済みなら v5.4 用の追加SQLは不要です。会社別資材名と注文承認状態は既存 tenant_store に保存されます。
